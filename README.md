# Loki — плагин для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa): поиск и просмотр через **ваш собственный аккаунт** на сайте, адрес которого вы указываете сами. Плагин не содержит ни видео, ни ссылок на сайты.

Что умеет:
- кнопка **Loki** на карточке фильма рядом со «Смотреть» (и в окне «Смотреть»);
- экран со списком серий: кнопки озвучки, сезона и качества, отметки ✓ и полоска прогресса;
- озвучка и сезон запоминаются для каждого сериала;
- автопереход на следующую серию;
- кнопка **Назад** в панели плеера (OK во время просмотра → слева): закрывает плеер и возвращает к списку серий.
- кнопка **микрофона** в панели плеера (рядом с качеством): смена озвучки без выхода из видео, с того же места;
- кнопка **перезапуска Lampa** в шапке рядом с профилем.

## Что понадобится

- **Официальное приложение Lampa для Android** (телевизор, приставка или телефон).
  В других оболочках (MD Station, Lampa в браузере, Samsung/LG) плагин работать не будет: им не даёт обращаться к сайту ограничение браузера (CORS).
- **Свой аккаунт на сайте** и его адрес (зеркало) — email, пароль и адрес вписываются в настройках.

Компьютер или сервер не нужен: приложение само обращается к сайту, а плагин скачивается с GitHub.

## Установка

1. В Lampa откройте **Настройки → Расширения → Добавить плагин** и введите адрес:
   ```
   https://akatsuki-yuuyake.github.io/player-by-loki/loki.js
   ```
   Надпись «404» в списке расширений можно не замечать: так Lampa пишет про плагины, которых нет в её каталоге.
2. Полностью закройте и снова откройте Lampa.
3. **Настройки → Плеер → Тип плеера → Lampa** (встроенный).
   Иначе Android ответит «Подходящего медиаплеера не найдено», а кнопка «Назад», автопереход и отметки серий работают только во встроенном плеере.
4. **Настройки → Loki** — введите **Зеркало** (адрес сайта), **Email** и **Пароль**. Остальное можно не трогать.
5. Откройте фильм или сериал и нажмите **Loki**.

## Настройки плагина

| Поле | Что указать |
|---|---|
| Зеркало | адрес сайта, через который вы входите в аккаунт. Обязательное поле |
| Email / Пароль | данные от сайта. Хранятся только на этом устройстве |
| Интерфейс | «Экран со списком серий» или «Всплывающие окна» (запасной вариант) |
| Качество | Максимальное / до 4K / до 1080p / до 720p / до 480p / Спрашивать |
| Предпочитать HLS | включите, если видео не запускается |

## Если что-то не работает

| Сообщение / симптом | Что делать |
|---|---|
| `Подходящего медиаплеера не найдено` | Настройки → Плеер → Тип плеера → **Lampa** |
| `сетевая ошибка — нужна официальная Lampa для Android` | у вас не официальное приложение Lampa для Android — установите его |
| `укажите адрес сайта` | заполните поле **Зеркало** |
| `вход не удался` | проверьте email и пароль |
| `вход принят, но приложение не отдало cookie` | обновите приложение Lampa до последней версии |
| `ничего не найдено по «…»` | фильма нет на сайте под этим названием, или сайт недоступен — попробуйте другое зеркало |
| Видео не запускается | включите **Предпочитать HLS** |
| Новая версия плагина не появилась | GitHub Pages обновляет файл в течение нескольких минут — перезапустите Lampa чуть позже |

## Безопасность

- Email, пароль и cookie входа хранятся только в настройках Lampa на вашем устройстве и отправляются только на сайт, указанный в поле «Зеркало».
- Плагин ничего не отправляет автору или третьим лицам.

## Для разработки

```
loki.js            плагин (ES5, без сборки)
start.sh           раздача плагина с компьютера в локальной сети (порт 8000) — для проверки изменений
```

Каждое изменение — отдельный коммит; откат конкретного изменения: `git revert <коммит>`.
